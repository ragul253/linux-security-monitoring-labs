# Linux and Security Monitoring Labs

**Academic lab projects**

> Repository status: project overview published. Original source files, configurations and supporting documentation will be added later. No runnable implementation is included yet.

## Overview

Deployed ELK Stack and built Kibana dashboards for log analysis in a simulated industrial network using pfSense, Smokeping and ntopng. Separately configured Snort on a Linux VM in GNS3, simulated port scans and ping floods, and analysed logs to verify alert generation. These exercises took place in lab environments.

## Technologies

Ubuntu · ELK Stack · Kibana · Snort · GNS3 · pfSense
